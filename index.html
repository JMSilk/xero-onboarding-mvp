Account code mapping
Map each Storeganise account code to its exact Xero equivalent. Codes must match exactly (case-sensitive) before you can continue. If a code doesn't match, update it in Storeganise, then reload.
No changes are made to your Storeganise settings or Xero. All writes go to the add-on config only.

Site IDs & tracking categories Optional
This JSON maps your Storeganise site IDs to site names for Xero tracking categories. Confirm to write it to the add-on config, or skip and complete it later from settings.
Fetched from GET /sites. Written to the trackingCategories custom field in the add-on config.
Before completing this step, set up a tracking category in Xero:
  1. In Xero, go to Advanced accounting → Tracking categories
  2. Create a new tracking category named "Site" (or your preferred name)
  3. Add each site below as a category option — e.g. "Castle Donington"
